# Enzo Palavicino — Portfolio

A lightweight, single-page software engineering portfolio built with semantic HTML, modern CSS, and vanilla JavaScript.

## Local preview

```bash
python3 -m http.server 4173
```

Then open `http://localhost:4173`.

## Deployment

The repository is a GitHub Pages user site (`Enzo-Palavicino.github.io`). GitHub Pages serves the files in the root of the `main` branch directly, so no framework build, generated output, or base-path configuration is required.

Production URL: https://Enzo-Palavicino.github.io

## Stack

- HTML5
- CSS3
- Vanilla JavaScript
- GitHub Pages

There are no runtime dependencies or package installation steps.
